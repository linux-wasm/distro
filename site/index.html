Disk

What you add, change and delete is kept in a disk image in this browser's storage for this site; the system itself is read-only and comes with the page.

Network

A page cannot open network connections itself. With a proxy (linux-wasm/netproxy, or any Wisp server) the system reaches the network through it; without one it has none. A page loaded over https can only use a wss:// proxy, or one on this computer (ws://127.0.0.1…).
